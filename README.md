# 📌 Project Overview

This project demonstrates the application of **Statistics using Python** on a Petrol Consumption dataset. It focuses on understanding data distributions, central tendency, variability, skewness, outlier detection, and relationships between variables through statistical techniques and visualizations.

The notebook provides a practical foundation for anyone beginning Data Analytics or Machine Learning.

---

# 🎯 Objectives

- Understand descriptive statistics
- Calculate measures of central tendency
- Analyze data distribution
- Detect skewness
- Identify outliers
- Study variable relationships
- Visualize statistical patterns
- Build a strong foundation for data analysis
